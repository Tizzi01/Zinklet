# Zinklet

Bring finished art to life with animated **invisible ink**. Import a drawing, brush ink over the parts
you want to move (line boil, jitter, wobble, shake, crumpled paper), export a looping MP4 or GIF.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:5173 and tap **Try sample art**, or drop in your own PNG/JPG.

To try it on your phone/tablet on the same Wi-Fi, open the "Network" URL that `npm run dev` prints.

## Build

```bash
npm run build
```

Outputs a static site in `dist/` that can be hosted anywhere (Netlify, Vercel, Cloudflare Pages).

See `CLAUDE.md` for architecture, UX principles and the roadmap.
